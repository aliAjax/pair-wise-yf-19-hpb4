# hxyfront-62007 植物标本馆入库

源提示词编号：9

开发一个植物标本馆压制标本入库前端项目，工作人员可以录入采集号、物种名称、采集地点、海拔、生境描述、采集人、压制状态、鉴定状态和馆藏位置。页面需要有入库队列、鉴定状态筛选、采集地点信息卡、馆藏柜位记录和单份标本详情页。

## 功能

- 入库队列、鉴定状态筛选（含“待复核”）、采集地点信息卡、馆藏柜位记录、单份标本详情页
- 库房环境台账：值班员每班登记库房编号、温度、湿度，超上限（24℃ / 60%RH）记为异常
- 同一库房连续两班异常自动冻结库内柜位：在柜标本留在原处并在队列标记“待复核”，冻结柜位不再接收新标本
- 异常消除（登记正常读数）后进入待复核，须另一名值班员复核确认才解冻，未复核的保持冻结
- 入库队列、采集地点信息卡、单份详情均显示所属柜位最近读数；入库登记选择柜位时可先核对环境

## 技术栈

React + Vite + TypeScript

## 本地运行

```bash
npm install
npm run dev
```
